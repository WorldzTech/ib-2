# ib-2 — тренажёры после второй встречи

Интерактивные тренажёры курса Route Kids × ИБ Ozon по теме «цифровой след».
Сделаны по образцу `ib-1`: React + TypeScript + Vite, та же дизайн-система.

## Тренажёры

| Маршрут | Тренажёр | Что закрепляет |
| --- | --- | --- |
| `/dossier` | Собери досье | из открытых постов собирается карточка человека |
| `/password` | Угадай пароль | пароль `Motya2016` собран из клички питомца и года рождения |
| `/footprint` | Намеренный или случайный | два вида цифрового следа |
| `/mosaic` | Мозаика: кто это? | безобидные факты опасны в сборке, ник склеивает профили |

Все задания текстовые: картинок в упражнениях нет, иллюстрации используются только в оформлении.

## Запуск

```bash
npm ci
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run lint
```

## Деплой

`Dockerfile` собирает статику и раздаёт её через Caddy. Домен по умолчанию — `ib-2.kidsroute.ru`,
переопределяется переменной `SITE_ADDRESS`:

```bash
SITE_ADDRESS=:80 docker compose up --build
```
